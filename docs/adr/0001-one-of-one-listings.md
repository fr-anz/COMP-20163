# Use one-of-one garment listings for MVP v1

MVP v1 uses thrift clothing, with each listing representing one physical garment, one fixed size, and one available unit to keep the first working release manageable. This release is the foundation for continued improvement toward the graded submission; the one-of-one restriction applies to v1 and may be revised as later versions' requirements develop. Preserve and improve the working application across iterations, revisiting its niche, variants, and inventory model when needed rather than treating v1 constraints as permanent requirements.
